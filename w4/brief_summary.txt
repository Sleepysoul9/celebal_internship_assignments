An end-to-end data pipeline was implemented using Azure Blob Storage and Azure Data Factory. A CSV file named superstore.csv was uploaded to the source container. Azure Data Factory was configured with a Linked Service and source and destination datasets. A Get Metadata activity was used to retrieve file information and validate the source file. A Copy Data activity was then used to transfer the data from the source container to the destination container. The pipeline was executed successfully using Debug mode and monitored through Azure Data Factory. IAM roles, including Reader and Storage Blob Data Contributor, were assigned to enable secure access between Data Factory and Storage. The successful execution confirmed the end-to-end movement and validation of data.
